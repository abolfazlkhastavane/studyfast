# آکادمی دکتر خسته — نسخه‌ی رایگان (Cloudflare Workers + GitHub)

این نسخه، جایگزین کامل و رایگان پلاگین وردپرسی قبلیه. فقط دو بخش «درسنامه (مباحث)» و
«فلش‌کارت + مرور SM-2» رو داره (بلاگ عمومی، تسک روزانه، دستیار Gemini و ربات تلگرام
عمداً حذف شدن تا فاز اول ساده و سبک بمونه).

## معماری، خیلی خلاصه
- **Cloudflare Workers** میزبان کد و رابط کاربریه (رایگان، پلن Free کافیه).
- **یک ریپوی گیت‌هاب** به‌جای دیتابیس عمل می‌کنه: همه‌چیز توی یک فایل `data/db.json`
  ذخیره می‌شه. هر ذخیره = یک کامیت جدید => تاریخچه و بکاپ کامل و خودکار، رایگان.
- **دیپلوی**: با هر `push` به شاخه‌ی `main`، گیت‌هاب اکشنز خودش دیپلوی می‌کنه.
- **تنظیمات**: بعد از راه‌اندازی اولیه، توکن گیت‌هاب و رمز عبور از همون پنل تنظیمات
  داخل اپ قابل تغییرن (بدون نیاز به دست زدن به wrangler یا گیت‌هاب).

> نکته: خودِ این ریپو (کدِ اپ) می‌تونه همون ریپوی داده هم باشه، یا یک ریپوی جدا و
> **خصوصی** بسازی فقط برای `data/db.json` (پیشنهاد می‌شه، چون این فایل ممکنه اطلاعات
> شخصی مطالعه‌ت رو داشته باشه).

## مرحله ۱ — ساخت ریپوی گیت‌هاب
۱. این پوشه رو به یک ریپوی جدید توی گیت‌هاب پوش کن (می‌تونه همین ریپو باشه یا یکی جدید).
۲. اگه می‌خوای داده‌ها جای دیگه‌ای باشن، یک ریپوی **خصوصی** دیگه هم بساز (مثلاً
   `drkhaste-academy-data`) — فقط همین، خالی، لازم نیست چیزی توش باشه.
۳. یک **Personal Access Token (fine-grained)** بساز:
   `github.com/settings/personal-access-tokens/new` → دسترسی محدود به همون ریپوی
   داده → Permissions → **Contents: Read and write**.

## مرحله ۲ — ساخت اکانت و توکن کلادفلر
۱. یک اکانت رایگان Cloudflare بساز (اگه نداری).
۲. از `dash.cloudflare.com` → My Profile → API Tokens → **Create Token** →
   قالب «Edit Cloudflare Workers» رو انتخاب کن (دسترسی به Workers Scripts: Edit).
۳. Account ID رو از داشبورد کلادفلر (سمت راست صفحه‌ی هر دامنه یا Workers) کپی کن.

## مرحله ۳ — تنظیم Secretهای گیت‌هاب اکشنز
توی ریپوی کد، برو به Settings → Secrets and variables → Actions و این‌ها رو اضافه کن:

| نام Secret          | مقدار                                              |
|---------------------|-----------------------------------------------------|
| `CF_API_TOKEN`      | توکنی که در مرحله‌ی ۲ ساختی                          |
| `CF_ACCOUNT_ID`     | Account ID کلادفلر                                   |
| `CF_WORKER_NAME`    | `drkhaste-academy` (یا هر اسمی که در wrangler.toml گذاشتی) |
| `DATA_REPO_TOKEN`   | توکن گیت‌هابی که در مرحله‌ی ۱ ساختی                   |
| `DATA_REPO`         | نام ریپوی داده، به فرمت `owner/repo`                 |
| `DATA_REPO_BRANCH`  | معمولاً `main`                                       |
| `ADMIN_PASSWORD`    | رمز عبوری که می‌خوای برای ورود به اپ استفاده کنی      |

## مرحله ۴ — اولین دیپلوی + راه‌اندازی سکرت‌ها
۱. یک push به شاخه‌ی `main` بزن (یا از تب Actions، ورک‌فلوی «Deploy to Cloudflare
   Workers» رو دستی اجرا کن). این فقط کد رو دیپلوی می‌کنه؛ هنوز سکرتی ست نشده.
۲. از تب **Actions** ریپو، ورک‌فلوی **«Seed / Reset Worker Secrets»** رو پیدا کن و
   دستی اجرا کن (Run workflow). این یک‌بار همه‌ی سکرت‌های لازم (شامل هشِ رمز عبورت
   و توکن گیت‌هاب) رو روی Worker ست می‌کنه.
۳. آدرس Worker (چیزی شبیه `drkhaste-academy.<subdomain>.workers.dev`) رو از داشبورد
   کلادفلر یا خروجی دیپلوی پیدا کن و بازش کن.
۴. با همون `ADMIN_PASSWORD` وارد شو 🎉

از این به بعد:
- هر push به `main` فقط کد رو آپدیت می‌کنه (سکرت‌ها دست نمی‌خورن).
- تغییر رمز عبور یا توکن گیت‌هاب رو از داخل خود اپ، تب **تنظیمات** انجام بده.
- اگه یه روز رمز رو کامل فراموش کردی، دوباره ورک‌فلوی Seed رو با `ADMIN_PASSWORD`ی
  جدید در Secrets اجرا کن.

## توسعه‌ی محلی (اختیاری)
```bash
npm install
npx wrangler secret put GITHUB_TOKEN
npx wrangler secret put GITHUB_REPO
npx wrangler secret put GITHUB_BRANCH
npx wrangler secret put ADMIN_PASSWORD_HASH   # با اسکریپت seed-secrets.mjs بسازش
npx wrangler secret put SESSION_SECRET
npm run dev
```

## محدودیت‌های شناخته‌شده (فاز اول)
- فقط یک ادمین؛ چند-کاربره نیست.
- کل دیتابیس یک فایل JSON روی گیت‌هابه — برای حجم شخصی (چند صد مبحث/کارت) عالیه؛
  اگه خیلی خیلی بزرگ شد (چند مگابایت) باید به چند فایل تقسیم بشه (فاز بعدی).
- بدون کش (هر ریکوئست مستقیم از گیت‌هاب می‌خونه) — برای استفاده‌ی تک‌نفره کاملاً کافیه
  (سقف مجاز گیت‌هاب: ۵۰۰۰ ریکوئست در ساعت).
- تلگرام، دستیار Gemini AI، و تسک روزانه در این فاز نیستن؛ اگه لازم شد بگو تا اضافه کنم.
